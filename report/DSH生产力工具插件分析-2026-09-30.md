## 复核提示

- 先按类别查看 README 和安装方式，再判断是否适合纳入默认插件集合。
- `npm_weekly` 和 Release 下载只说明分发信号，不代表活跃用户数。
- 生产力类别仍需人工复核同质化复制、误命中和 README 夸大描述。
