## 三、逐行理完后的新发现

1. **「会话/Web UI 增强」才是真正的第一大类（169 个，14.7%）**——之前按目录站品类看是"UI 主题"，逐个读完后发现大头其实是功能微增强：会话导航条（至少 8 个）、自动折叠（5+）、输入历史（4+）、消息撤回（4+）、会话管理器（8+）。单个都是小工具，合起来说明官方 Web UI 交付了 MVP、细节全靠社区补。
2. **PerryLink 是生态最高产的“全职插件工坊”**：活跃集里有 **24 个** PerryLink 仓库（auto-review、permission-rules、memento、checkpoint-rewind、lsp-actions、defend、local-ai……），质量稳定且全部适配 rc.1，相当于一个人的 JetBrains。
3. **omdsh-dev 官方线在活跃集里有 30+ 个仓库**，全部适配 rc.1——官方周边的维护纪律明显好于社区平均。
4. **安全类从"洼地"变成"暗流"**：41 个活跃仓库里出现了完整谱系——权限档位（auto-approve 系 5+）、注入防御（dsh-defend、injection-guard）、插件静态扫描（dshscan、plugin-vet、x-ray）、运行时防护（hol-guard）、时间旅行审计（time-travel）。供应链风险正在被社区自组织地消化。
5. **远程赛道的存活格局**：29 个活跃仓库里三条路线清晰——Web 网关（dsh-remote-web-gateway 116★）、APK 打包（dsh-mobile-apk 112★）、中继+多客户端（liguobao 48★）。手机扫码/FRP 教程流大量死在 rc.1 上。
6. **娱乐层是"活跃的"**：40 个桌宠/皮肤/小游戏全部在 rc.1 后有 push——玩物不是弃物，是留存的粘合剂。
7. **峰谷计费成了一个小型亚品类**：DeepSeek 官方分时定价催生了至少 7 个"峰谷提醒/错峰调度"插件（offpeak-saver、tidewatch、tide、peak-pricing……），电费焦虑的赛博复刻。

## 四、结论

1,150 个真活跃插件的构成：**约 60% 是真实生产力**（搜索/记忆/视觉/Provider/工程化/安全/远程/垂直），**约 25% 是体验补齐**（UI 增强/桌面壳/会话管理，有用但同质化），**约 10% 是娱乐层**，**约 5% 是市场与教程这类元生态**。品类密度前三（UI 增强、搜索、桌面壳）恰好都是官方短板所在——这个生态的分工本质是"官方做内核，社区补周边"。
